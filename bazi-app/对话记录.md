**已查证的"祖宗之法"关键规则：**

### 排盘铁律（严格实现清单）
1. **年柱以「立春」交节时刻为界**——不是农历正月初一，也不是公历1月1日。立春前出生用上一年干支。
2. **月柱以十二「节」划分**（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒），**用"节"不用"气"**；月干用「五虎遁」。
3. **日柱以零点为日始**；区分早子时(0-1点)/晚子时(23-0点)。
4. **时干用「五鼠遁」**。
5. **真太阳时校正**：按出生地经度修正（每度差4分钟），并处理 1986–1991 中国夏令时还原。
6. **大运顺逆以「年干」阴阳为准**（非日干！这是最常见的错误）：阳年男/阴年女顺排，阴年男/阳年女逆排；从月柱起顺/逆排六十甲子。
7. **起运岁数**：出生时刻到最近一「节」的精确时间差，**3天=1岁，1天=4个月，1时辰=10天**。
8. **地支藏干、十神、纳音、神煞、刑冲合害** 全部按传统表推算。
9. **格局取用**依《子平真诠》月令取格、《穷通宝鉴》调候用神等古法。

| 4 | 时柱用五鼠遁 | 时支按时辰，时干按日干遁 |

### 解读模块设计（两块独立）

#### ① 纯古法知识库（前端内置，不走 LLM，零臆造）
- 结构化 JSON/TS 规则库，按命局特征匹配输出。
- 内容来源：从《子平真诠》《滴天髓》《穷通宝鉴》《三命通会》《渊海子平》提炼的断语规则。
- 输出形如：`命主日主为甲木，生于寅月得令，月令透比肩→建禄格，古法断：...`

#### ② 规则库 + LLM 润色（走 API Route）
- 先由规则库提取命局结构化特征（格局/用神/喜忌/大运走势）。
- 再把特征 + 古法约束 prompt 一起喂给 LLM，**只让它组织语言、不得引入规则库以外的新断语**。
- Prompt 硬约束示例：`仅依据以下古法规则库输出，禁止编造、禁止引用规则库外的命理结论，风格沉稳文言白话相间。`
- 后端只暴露一个 `/api/interpret` 端点；用户在 UI 上单独点"AI 润色解读"才调用。

### 页面与功能
1. **首页/排盘页**：输入公历年月日时 + 性别 + 出生地 → 排盘。
2. **命盘展示**：四柱表（干/支/藏干/十神/纳音/神煞/空亡/旺衰）+ 大运表 + 流年 + 五行能量图 + 刑冲合害关系标注。
3. **解读区**（用户可选展开）：Tab 切换「古法断语」/「AI 润色解读」。
4. **我的命盘**：localStorage 存多份，可命名、对比、删除。
5. **关于/古法说明**：列出所依古籍与排盘规则，透明可溯源。

### 技术栈小结
- **前端/全栈**：Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **排盘引擎**：纯 TS 函数库（可单独单测，确保正确性）

- **图表**：ECharts（五行能量/大运走势）
- **存储**：localStorage（免登录）
- **LLM**：OpenAI 兼容接口，默认 GLM，`.env` 可配
- **测试**：用已知命例做排盘正确性回归测试
