# passlib 1.7.4 is unmaintained and its bcrypt backend probes the hash with a
# >72-byte test secret. bcrypt >= 5 rejects that probe with ValueError, so a
# bare passlib[bcrypt] resolves to a version where every get_password_hash()
# call raises (4.1-4.3 still work but log a version warning). 4.0.1 is the last
# release passlib handles cleanly, so pin it.

bcrypt==4.0.1
